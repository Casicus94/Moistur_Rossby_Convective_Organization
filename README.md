# Moisture and Wind Effects of Rossby Waves on Western Pacific ITCZ Breakdown Events
Scripts and analysis notebooks supporting the study on the influence of Rossby-wave–driven moisture advection on Intertropical Convergence Zone (ITCZ) breakdown events in the Western Pacific Warm Pool using high-resolution WRF simulations and machine-learning sensitivity experiments. 


The paper can be found here: https://doi.org/10.1002/qj.70131
